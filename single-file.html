02 About

Self-taught, and already shipping.

“I didn't wait for a course to finish before I started building.”

Harsh, on how this started

I'm a BCA student in my first semester and a self-taught full-stack web developer. I started out of curiosity, and instead of collecting tutorials I jumped straight into real projects and worked out the missing pieces along the way.

Since then I've built and shipped several full-stack apps: movie discovery, weather dashboards, small utilities, mostly with React, Node, Express and MongoDB. Each one taught me something the previous one didn't. How to structure an API so it stays readable. How to handle data that arrives late, or not at all. And how much of the quality lives in the small interface decisions nobody is supposed to notice.

Formal computer science is only starting for me. I already know it's what I want to keep doing, so I'd rather be useful now than wait until a degree says I am. If you have something to build, or a codebase that needs a careful pair of hands, I'd like to hear about it.
